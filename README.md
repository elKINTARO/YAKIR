# Yakir (Якір)

Застосунок для роботи з тривожністю. Ядро продукту — цикл емпіричної перевірки:
зафіксувати конкретний прогноз під час тривоги, через 24 години перевірити, що
сталося насправді, і накопичити особисту статистику калібрування.


## Три правила, які не порушуються

1. Дані записів ніколи не залишають пристрій у відкритому вигляді.
2. Прогноз не можна редагувати після створення.
3. Застосунок не називає себе терапією, не діагностує і не дає гарантій.

## Структура

```
apps/mobile/       Expo-застосунок (React Native, expo-router, TypeScript)
services/api/      FastAPI-проксі для AI-сесій (Фаза 2)
packages/          Спільні пакети між застосунком і сервісом
docs/adr/          Архітектурні рішення
```

## Швидкий старт

```sh
pnpm install
pnpm --filter @yakir/mobile exec expo run:android
```

Expo Go не використовується: шифрування бази через SQLCipher, secure store і
офлайн-розпізнавання мовлення потребують нативного коду. Працюємо з dev client.

## Перевірки

```sh
pnpm typecheck
pnpm lint
pnpm test
```

Покриття тестами теки `apps/mobile/src/domain` має бути стовідсотковим. Там живе
логіка планування нагадувань і підрахунку статистики, і помилка в ній означає
хибний висновок користувача про власне життя.

## Гілки

`main` містить лише релізи з тегами. Робота йде через `develop` і короткоживучі
гілки `feature/*`, `fix/*`, `chore/*`. Деталі — [CONTRIBUTING.md](CONTRIBUTING.md).
